```
@startuml
title <b>Последовательность регистрации и ремонта дефекта</b>

actor Контролёр
participant Система
actor Диспетчер
actor Бригадир
actor Ремонтник

Контролёр -> Система: Обнаружен дефект
Система -> Контролёр: Запрос данных о дефекте
Контролёр -> Система: Данные дефекта (место, описание, фото)
Система -> Система: Сохранение дефекта
Система -> Диспетчер: Уведомление о новом дефекте

Диспетчер -> Система: Запрос статуса ремонтных зон
Система -> Диспетчер: Статус зон (свободные/занятые места)
Диспетчер -> Система: Назначение зоны и места
Система -> Система: Обновление статуса автомобиля
Система -> Бригадир: Уведомление о новом задании

Бригадир -> Система: Просмотр деталей дефекта
Система -> Бригадир: Детали дефекта
Бригадир -> Система: Запрос доступных ремонтников
Система -> Бригадир: Список доступных ремонтников
Бригадир -> Система: Назначение ремонта ремонтнику
Система -> Ремонтник: Уведомление о назначении

Ремонтник -> Система: Фиксация начала ремонта
Система -> Система: Запись времени начала
Ремонтник -> Система: Фиксация процесса ремонта
Система -> Система: Сохранение данных о ремонте
Ремонтник -> Система: Фиксация завершения ремонта
Система -> Система: Запись времени окончания
Система -> Контролёр: Уведомление о готовности к проверке
Система -> Бригадир: Уведомление о завершении ремонта

Контролёр -> Система: Проверка качества ремонта
alt Качество приемлемо
  Контролёр -> Система: Подтверждение успешного ремонта
  Система -> Система: Закрытие дефекта, освобождение места
else Качество не приемлемо
  Контролёр -> Система: Отклонение ремонта
  Система -> Ремонтник: Уведомление о необходимости доработки
  Ремонтник -> Система: Фиксация доработки
  Система -> Контролёр: Уведомление о готовности к повторной проверке
end

@enduml
```
