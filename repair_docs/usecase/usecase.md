# диаграмма случаев использования
## Акторы
Контролёр качества (QC Inspector) - сотрудник отдела контроля качества, обнаруживающий дефекты

Диспетчер (Dispatcher) - отвечает за распределение автомобилей по ремонтным зонам

Ремонтник (Repair Technician) - рабочий, выполняющий ремонтные работы

Бригадир (Foreman) - руководитель ремонтной бригады

Начальник цеха (Shop Head) - руководитель производственного цеха

Бухгалтерия (Accounting) - сотрудники бухгалтерии для учёта рабочего времени

Администратор (System Admin) - системный администратор, управляющий справочниками

Внешние системы (ERP/MES) - существующие системы предприятия

## Основные сценарии использования
### Для контроля качества:
* Регистрация дефектов при обнаружении
* Возврат автомобилей на конвейер после ремонта
* Формирование отчётов за смену

### Для диспетчера:
* Назначение дефектов на ремонт
* Мониторинг статуса ремонтных зон
* Распределение автомобилей по зонам

### Для ремонтника:
* Выполнение диагностики
* Начало и завершение ремонтных работ
* Регистрация начала смены
* Загрузка фотографий выполненных работ

### Для бригадира:
* Назначение ремонтов конкретным рабочим
* Мониторинг работы бригады
* Формирование отчётов по бригаде

### Для руководства:
* Начальник цеха получает сводные отчёты
* Бухгалтерия получает данные для расчёта зарплаты

### Для администратора:
* Управление справочниками (зоны, места, бригады)
* Настройка системы

## Ключевые зависимости
* Назначение ремонта зависит от информации о статусе ремонтных зон
* Завершение ремонта включает загрузку документов/фото
* Все отчёты используют данные о выполненных ремонтах
* Бухгалтерский отчёт использует данные о регистрации смен

## Интеграции
Система получает данные из внешних систем:
* ERP - информация о заказах и автомобилях
* MES - данные о производственном плане и статусе конвейера
