## Основные компоненты
* Configuration - этот компонент используется в основном validation, в нём какие-то эксперименты, шаги, критерии, гипотезы, а точнее их конфигурация
* Factory - какая-то абстракция для вызова компонентов Experiment или напрямую Persistence
* Experiment - здесь запускается эксперимент и выполняются различные шаги. Есть интерфейс IExperimentStep, который по-разному реализуют несколько типов шагов, какие-то из них идут в компонент Generator
* Generator - различные реализации генерации RVS
* Test, TestStatistics, CVCalculator - компоненты для тестирования
* Worker - я не понимаю, что он делает, видимо асинхронное взаимодействие для чего-либо, возможно для сбора статистики, но при этом этот компонент обращается только к Test и TestStatistics
* Report - компонент для отчётности, использующий компонент Configuration, видимо для построения структуры
* Persistence - вообще этих компонента два: в модулях Experiment и Criteria. Занимаются они в Experiment случайными значениями, временной сложностью и экспериментами, а в Criteria - пределами распределения и критическими значениями. Занимается соответственно постоянным хранилищем экспериментов и прочего
## Примерный флоу
1. В командной строке задаем конфигурацию
2. В Validation валидируем конфигурацию
3. Создаем эксперимент по конфигурации
4. Проводим эксперимент
5. Сохраняем результаты эксперимента
6. Строим отчет по результатам эксперимента

Параллельно с этим тестируем эксперименты и сохраняем в Persistence TimeComplexity и LimitDistribution
