# Описание состояний и переходов
## Состояния
Idle (ВЫКЛЮЧЕНА) - начальное состояние, микроволновка подключена к питанию, но не активна. Дверца закрыта.

DoorOpen (ДВЕРЦА ОТКРЫТА) - состояние, когда дверца микроволновки открыта. В этом состоянии можно загружать или выгружать пищу.

TimeSet (УСТАНОВКА ВРЕМЕНИ) - состояние программирования таймера. Пользователь устанавливает время приготовления.

Cooking (НАГРЕВ) - активное состояние приготовления пищи. Магнетрон включен, таймер отсчитывает время.

Paused (ПАУЗА) - приостановка нагрева. Возникает при открытии дверцы во время приготовления.

Finished (ЗАВЕРШЕНО) - состояние по окончании таймера. Микроволновка подаёт звуковой сигнал.

Error (ОШИБКА) - состояние при обнаружении неисправности. Все системы отключены.

## Переходы
### Основные переходы:
* Idle → DoorOpen: При открытии дверцы в выключенном состоянии
* DoorOpen → Idle: При закрытии дверцы
* Idle → TimeSet: При нажатии цифровой клавиши для установки времени
* TimeSet → TimeSet: При нажатии дополнительных цифр для увеличения времени
* TimeSet → Idle: При нажатии кнопки СТОП
* TimeSet → Cooking: При нажатии кнопки СТАРТ (при закрытой дверце)
* Cooking → Paused: При открытии дверцы во время приготовления
* Paused → Cooking: При закрытии дверцы и нажатии СТАРТ
* Paused → TimeSet: При нажатии СТОП и закрытии дверцы
* Cooking → TimeSet: При нажатии СТОП во время приготовления
* Cooking → Finished: При достижении таймером нуля
* Finished → Idle: При любом действии пользователя (нажатие кнопки, открытие/закрытие дверцы)
* Finished → DoorOpen: При открытии дверцы после завершения

### Переходы при ошибках:
* Idle → Error: Обнаружение неисправности в выключенном состоянии
* TimeSet → Error: Обнаружение неисправности при установке времени
* Cooking → Error: Обнаружение неисправности во время нагрева
* Paused → Error: Обнаружение неисправности в состоянии паузы
* Error → [*]: Отключение питания при ошибке
