# Общее описание системы
Система предназначена для автоматизации учёта дефектов сборки на автомобильном заводе. Она обеспечивает:
* Отслеживание автомобилей на всех этапах производства
* Регистрацию дефектов и управление ремонтными работами
* Управление ремонтной инфраструктурой (зоны, места, бригады)
* Генерацию отчётов для различных подразделений завода

## 1. Перечисления
    * CarStatus - статусы автомобиля в процессе производства:
        * IN_PRODUCTION - в производстве
        * PAINTING - в покраске
        * ASSEMBLY - на сборке
        * QUALITY_CONTROL - на контроле качества
        * IN_REPAIR - в ремонте
        * SHIPPED - отгружен
    * RepairStatus - статусы ремонта:
        * REGISTERED - зарегистрирован
        * IN_PROGRESS - в процессе
        * COMPLETED - завершён
    * SpotStatus - статусы ремонтного места:
        * FREE - свободно
        * OCCUPIED - занято
        * UNDER_MAINTENANCE - на обслуживании
    * Role - роли сотрудников:
        * WORKER - рабочий
        * FOREMAN - бригадир
        * DISPATCHER - диспетчер
        * QUALITY_CONTROLLER - контролёр качества
        * SHOP_HEAD - начальник цеха
        * ACCOUNTANT - бухгалтер

## 2. Основные сущности
### Car
    * Содержит информацию об автомобиле: VIN, комплектация, цвет, статус
    * Методы управления статусом и дефектами
    * Связь с заказом и списком дефектов

### Order
    * Представляет заказ от дилера на производство автомобилей
    * Содержит сроки выполнения и список автомобилей
    * Методы для отслеживания прогресса выполнения заказа

### Defect
    * Описывает обнаруженный дефект: местоположение, описание, дата обнаружения
    * Связь с автомобилем и работником, обнаружившим дефект
    * Методы для создания задания на ремонт

### Repair
    * Представляет процесс ремонта конкретного дефекта
    * Содержит временные метки начала и окончания ремонта
    * Связь с ремонтным местом и работниками
    * Методы управления процессом ремонта

## 3. Ремонтная инфраструктура
### RepairZone
    * Представляет ремонтную зону на участке конвейера
    * Содержит список ремонтных мест и текущую бригаду
    * Методы для управления доступностью мест

### RepairSpot
    * Конкретное место в ремонтной зоне, где находится автомобиль
    * Методы для занятия и освобождения места

### RepairTeam
    * Группа работников под руководством бригадира
    * Связь с ремонтной зоной и работниками
    * Методы управления бригадой и назначения ремонтов

## 4. Персонал
### Employee
    * Базовый класс для всех работников
    * Содержит общую информацию: идентификатор, имя, роль
    * Методы для регистрации смены и работы с ремонтами

### Dispatcher
    * Отвечает за распределение автомобилей по ремонтным зонам
    * Методы для просмотра статуса зон и назначения автомобилей
    * Генерирует отчёт о диспетчеризации

### QualityController
    * Обнаруживает дефекты и проверяет качество автомобилей
    * Методы для регистрации дефектов и одобрения автомобилей
    * Генерирует отчёт контроля качества

### Foreman
    * Руководит ремонтной бригадой
    * Методы для назначения ремонтов и контроля производительности
    * Генерирует отчёт по бригаде

### ShopHead
    * Управляет цехом, оптимизирует расписание ремонтов
    * Генерирует сводный отчёт по цеху

### Accountant
    * Ведёт учёт отработанного времени
    * Генерирует бухгалтерские отчёты и расчёт заработной платы

## 5. Отчёты
### DispatchReport
    * Содержит информацию о распределении автомобилей по зонам
    * Генерируется диспетчером

### QualityControlReport
    * Статистика по ремонтам: количество, места дефектов, среднее время
    * Генерируется контролёром качества

### ShopHeadReport
    * Сводная информация по ремонтам в цехе
    * Генерируется начальником цеха

### ForemanReport
    * Детальная информация по каждому работнику бригады
    * Генерируется бригадиром

### AccountingReport
    * Учёт отработанных смен и расчёт заработной платы
    * Генерируется бухгалтером
