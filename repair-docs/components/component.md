# Описание компонентов
## 1. Пользовательские интерфейсы
Web Application - Веб-приложение для всех сотрудников

Admin Panel - Админ-панель для управления системой

## 2. API Gateway
Единая точка входа для всех запросов. Обеспечивает безопасность и маршрутизацию.

## 3. Основные сервисы (Core Services)
Production Service - Управление производством, заказами, автомобилями

Defect Service - Регистрация и учёт дефектов

Repair Service - Управление ремонтами, зонами, бригадами

## 4. Вспомогательные сервисы (Support Services)
User Service - Управление пользователями, аутентификация

Report Service - Генерация всех типов отчётов

Notification Service - Отправка уведомлений

## 5. Базы данных
Main DB - Основная база для операционных данных

Report DB - Оптимизирована для отчётов и аналитики

## 6. Внешние системы
ERP System - Управляет бизнес-процессами всего предприятия

MES System - Управляет реальным производственным процессом на заводе

## Ключевые взаимодействия
### Процесс регистрации дефекта:
    1. Контролёр через WebApp регистрирует дефект
    2. Запрос идёт через API Gateway в Defect Service
    3. Defect Service сохраняет данные в Main DB
    4. Repair Service получает задание на ремонт
    5. Notification Service оповещает диспетчера

### Генерация отчёта:
    1. Менеджер запрашивает отчёт через WebApp
    2. Report Service собирает данные из Main DB и Report DB
    3. Формируется отчёт и возвращается пользователю

### Интеграция с внешними системами:
    1. Production Service получает заказы из ERP
    2. Production Service отслеживает статус автомобилей через MES
    3. После ремонта система уведомляет MES о возврате автомобиля
