# Описание развёртывания системы
## 1. Клиентские устройства
ПК сотрудников - компьютеры в офисах для диспетчеров, контролёров качества, бригадиров, руководителей

Планшеты - мобильные устройства для рабочих и бригадиров в ремонтных зонах

## 2. Основная инфраструктура
Балансировщик нагрузки - распределяет запросы между веб-серверами

Веб-серверы (2 экземпляра) - обрабатывают HTTP-запросы, отдают фронтенд

API Шлюз - единая точка входа для всех API-запросов

Микросервисы (6 штук) - каждый отвечает за свою бизнес-область

Промежуточное ПО - очередь сообщений для асинхронной обработки (Kafka) и кэш для ускорения (Redis)

## 3. Базы данных
Основная БД - хранит все операционные данные

БД отчётов - оптимизирована для аналитических запросов

Резервное копирование - обеспечивает сохранность данных

## 4. Внешние системы
ERP система - интеграция с управлением ресурсами предприятия

MES система - интеграция с системой управления производством

## 5. Производственная сеть
Сеть завода, к которой подключены планшеты рабочих и производственное оборудование
