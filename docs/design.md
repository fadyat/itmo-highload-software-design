# Дизайн интерпретатора командной строки

**Команда**: [Фадеев Артем](https://github.com/fadyat), [Соколов Денис](https://github.com/DenChika)

## Цель

Разработать интерпретатор командной строки, поддерживающий:

- `cat` — вывести на экран содержимое файла;
- `echo` — вывести на экран свой аргумент (или аргументы);
- `wc` — вывести количество строк, слов и байт в файле;
- `pwd` — распечатать текущую директорию;
- `exit` — выйти из интерпретатора.

а также:

- full and weak quoting
- окружение (переменные окружения, пользовательские переменные)
- пайпы
- остальное считается вызовом внешних программ

## Архитектура

### Main Loop

**Назначение:** основной цикл программы.

**Функции:**

- Принимает строку ввода от пользователя.
- Передаёт её на обработку в `Lexer` -> `Parser` -> `Executor`.
- Обрабатывает команду `exit` для завершения программы.

**Пример работы:**

```
> echo "hello world"
```

---

### Lexer

**Назначение:** разбивает строку на токены.

**Функции:**

- Учитывает **одинарные (`'`) и двойные (`"`) кавычки**:
    - `'` — полное quoting (всё внутри трактуется буквально);
    - `"` — слабое quoting (разрешает подстановку переменных `$VAR`).

- Распознаёт пайпы (`|`) и знаки `=`.
- Формирует список токенов, например:

    ```
    echo "Hello $USER" | wc
    → [echo] ["Hello $USER"] [|] [wc]
    ```

---

### Parser

**Назначение:** преобразует токены в структуру команд.

**Функции:**

- Собирает команды с аргументами:

    ```rust
    Command {
        name: "echo",
        args: ["Hello $USER"]
    }
    ```

- Распознаёт пайплайны (`|`) и строит цепочку команд:

    ```rust
    Pipeline {
        commands: [
            Command("cat", ["file.txt"]),
            Command("wc", [])
        ]
    }
    ```

- Отдаёт результат `Executor`-у.

---

### Executor

**Назначение:** выполняет команды.

**Функции:**

- Получает от `Parser` структуру команд.
- Перед выполнением вызывает [`EnvironmentManager`](#environment-manager) для подстановки переменных
- Определяет, встроенная команда или внешняя:
    - **Встроенные:** `cat`, `echo`, `wc`, `pwd`, `exit`.
    - **Неизвестная:** вызывается как внешняя программа через системный вызов (`std::process::Command`).
- Реализует **пайплайны**:
    - Перенаправляет вывод одной команды на ввод следующей.
    - Пример: `cat file.txt | wc` выполняется как `stdout(cat) -> stdin(wc)`.

---

### Environment Manager

**Назначение:** управляет переменными окружения.

**Функции:**

- Хранит пары ключ-значение:

    ```rust
    HashMap<String, String>
    ```

- Поддерживает команды вида `NAME=value` (установка переменной).
- Выполняет **подстановку переменных `$VAR`** в строках (включая слабые кавычки):
    - `$VAR` заменяется на значение переменной;
    - Если переменной нет — подставляется пустая строка.
- Изначально инициализируется переменными из окружения ОС.

## Фазы разработки

- **Фаза 1**: реализация без подстановок и пайпов — `Lexer`, `Parser`, `Executor` для одиночных команд.
- **Фаза 2**: добавление пайпов, переменных окружения и кавычек.

## Диаграмма

<img width="1548" height="651" alt="image" src="https://github.com/user-attachments/assets/947999db-34ad-4a90-b8cb-ac88e2c92c41" />

MainLoop:
1. Обращается к Lexer, который разбивает строку на токены (tokenize), учитывая одинарные и двойные кавычки (handle_double_quotes, handle_single_quotes)
2. Превращает токены в Pipeline при помощи Parser (parse)
3. Pipeline в виде одной или нескольких команд выполняется Executor'ом, который
    * Выполняет встроенные команды (execute_builtin)
	* Выполняет внешние команды (execute_external)
	* Выполняет пайплайн целиком (execute_pipeline)
До выполнения Executor обращается к EnvironmentManager'у, который загружает переменные окружения из ОС и обновляет их (load_os_environment, expand_variables)
